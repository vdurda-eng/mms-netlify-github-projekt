# mms-netlify-github-projekt
Ovaj projekt je napravljen za svrhe vježba kolegija Multimedijalni Sustavi.
Na stranici može pronaći neke od mojih najdražih umjetničkih dijelova, te malo informacija o nijma: umjetnik, tehnika, dimenzije, umjetnički pokret, gdje je trenutačno izloženo, i barem jedan paragraf objašnjavajući što se nalazi na slikama.
